# 雾中酒馆 · 互动剧情小说

> 三部大世界观互动小说，女主可攻略任意角色，结局由你决定。

---

## 通用设定

### 女主体质 · 万缘体质

你天生散发一种难以言喻的亲和之力。无论是人、妖、神、魔，初见你时都会本能地产生好感。这不是魅惑术，而是一种源于灵魂的温暖——仿佛你本就是他们一直在等待的那个人。

- **效果**：所有角色初始好感度为「友善」（而非「陌生」）
- **限制**：好感≠服从。角色有自己的信念、立场和底线
- **成长**：你将学会掌控这股力量，从被动承受命运到主动选择未来

### 交互模式

- **关键节点**：系统提供 2-4 个选项，你的选择决定剧情走向
- **日常对话**：自由交流，你的言行会影响角色好感度
- **攻略判定**：累计选择和对话倾向决定最终结局路线

## 第三部 · 仙侠世界 — 《六界浮生》

**基调**：恢弘壮阔 · 宿命羁绊

六界并立——天界、人界、魔界、妖界、冥界、灵界。你是灵界遗孤，万缘体质让你成为六界争抢的存在。天界的高冷神君、魔界的霸道魔尊、妖界的妩媚狐仙、冥界的沉默判官……你的命运与六界的存亡紧紧相连。这一世，你要拯救苍生，还是只守护你在乎的人？
